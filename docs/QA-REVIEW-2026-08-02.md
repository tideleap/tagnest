## 二、质量评估

### 2.1 功能完整性
- 主链路完整：登录→收藏/批量/检索→标签/分组→导入导出→分享→概览，均有真实代码+测试支撑。
- **缺口**：AI 需要用户自行配置 provider+开启开关，否则 `loadAiConfig` 直接返回 null，**无任何文案提示"当前 AI 不可用"**——首次使用容易误以为功能坏了。

### 2.2 用户体验
- **多主题**一致性好（5 主题前后端、扩展同源），设置可持久化无闪屏。
- **导入进度**已修复（NDJSON 流式 + 尾部 flush），大文件有进度条。
- 潜在体验问题：
  - 登录失败/注册的报错反馈文案是否友好（需抽查）。
  - 移动端布局、键盘快捷键覆盖、无障碍对比度（WCAG AA）未专项验证。

### 2.3 操作流畅性
- 检索、列表分页基于 keyset cursor，QL 查询走索引；评估为流畅。
- 潜在风险：超大书签库（>1 万条）时 `/stats`、`/tags` 全量聚合的性能（当前无条件聚合）。

### 2.4 兼容性
- PWA / 扩展面向 Chromium；Firefox 的 MV3 差异（`chrome.storage`/`browser` 命名）未适配。
- 多主题采用 oklch（现代浏览器），对旧浏览器（<2023 Safari）可能不渲染配色 → 需要 fallback（见 R-09）。

### 2.5 数据准确性
- 导入去重基于 URL 规范化（strip utm/gclid 等），文件夹→标签映射准确。
- **边界**：CSV 首列若为 `=公式` 的"URL"会被 `canonicalUrl`（仅 http/https）过滤掉——但**导出的 CSV 标题/描述列若含 `=` 前缀**，下游 Excel 打开可能触发公式注入（见 R-04）。

### 2.6 异常处理
- 已修：越界实体（fromCodePoint RangeError→500）、NDJSON 尾部丢 result、D1 迁移阻塞部署。
- 未覆盖：网络抖动下的乐观更新回滚、并发同 URL 收藏竞态（409 已处理）、预览 token 过期（TTL 15min）提示是否友好。

## 四、优化需求清单（结构化，研发/产品可直接跟进）

> 每项：问题 → 模块 → 影响 → 优先级 → 建议方向 / 验收标准。

### P0（必须，安全/核心）
**REQ-01 注册安全加固**
- 问题：开放注册 + 无验证码 + 无邮箱验证 → 垃圾与滥用。
- 模块：认证。
- 影响：生产安全。优先级：**高**。
- 建议：加验证码（Turnstile/等）或**默认关闭注册**（`DISABLE_SIGNUP=true`）；可选邮箱验证；统一报错文案。
- 验收：新用户无法匿名机器人注册；`ALLOWED_EMAILS` 白名单生效；错误反馈不泄露邮箱是否已注册。

**REQ-02 AI 可用性可见化**
- 问题：AI 配置入口存在但默认静默无效果。
- 模块：AI 设置 / 书签卡片。
- 影响：功能可信度。优先级：**高**。
- 建议：`ai/settings` 未配置 provider 时，在设置页置明显"AI 未配置，自动标签/摘要不可用"状态条；书签卡片无 summary 时不显示空位。
- 验收：进入 AI 设置可见明确状态；无 key 时 autoTag 开关禁用并说明。

### P1（应做，体验/数据）
**REQ-03 ✅ 已满足（无需开发）——CSV 公式注入**
- 结论：导入与导出的 CSV 均已有公式注入防护（`csvCell` 对 `=+-\t@\r` 前缀加 `'` + 导入 URL http/https 白名单）。无需改动。
- 可加一项**测试用例**覆盖：构造 `=cmd` 标题导入→导出，确认导出保留 `'` 前缀（回归保护）。

**REQ-04 分享页接入多主题**
- 问题：分享页与主站视觉不一致（分享主题=布局枚举，配色固定）。
- 模块：分享 / 主题。
- 影响：产品一致性。优先级：**中**。
- 建议：分享的 `theme` 增加可选配色（复用 5 主题或保留默认）；至少让创建者可选主站主题。
- 验收：分享页可呈现 2 种以上配色且 accessible。

**REQ-05 台账别名呈现统一**
- 问题：F-P1-5/F-P1-6 open/done 双呈现易误读。
- 模块：开发基建/台账。
- 影响：项目可维护性。优先级：**中**。
- 建议：`backlog-check` 在 README/BACKLOG 导出时，别名项统一显示目标状态（如 `done →B7`），并允许按需隐藏。
- 验收：`npm run backlog:check` 输出与 BACKLOG.md 呈现一致，无 open/done 矛盾。

**REQ-06 oklch 旧浏览器降级**
- 问题：仅 oklch，旧 Safari 无 fallback 配色失效。
- 模块：主题。
- 影响：兼容性。优先级：**中**。
- 建议：主题块在 `--p-*` 前先给 `@supports not (color: oklch(0% 0 0))` 时用 hex/rgb 兜底或保留原有近似。
- 验收：在无 oklch 引擎下（或 DevTools 禁用）界面仍可读。

### P2（可选，打磨）
**REQ-07 大库统计性能与缓存**
- 问题：`/stats` 在超大库（>1 万条）下为全量 SQL 聚合，未压测（列表分页已用 keyset cursor，无 OFFSET 性能问题）。
- 模块：统计/概览。
- 影响：性能。优先级：**低-中**。
- 建议：对 `/stats` 加短缓存或条件聚合；大库下 `EXPLAIN` 校验。
- 验收：10 万条库下 /stats 与 /dashboard 首屏 p95 < 500ms。

**REQ-08 扩展兼容与更新体验**
- 问题：需手动 reload；Firefox MV3 命名差异。
- 模块：扩展。
- 影响：兼容/体验。优先级：**低**。
- 建议：`chrome.*` 适配 `browser.*` 别名；README 注明 reload 步骤（已写）。
- 验收：Firefox 能加载并收藏。

**REQ-09 无障碍（WCAG AA）专项**
- 问题：交互对比度/键盘/读屏未专项。
- 模块：全局 UI。
- 影响：包容性。优先级：**低**。
- 建议：抽检按钮/输入对比度（≥4.5:1）、焦点可见、ARIA。
- 验收：aXe/Lighthouse 无障碍 ≥90。

**REQ-10 导入/网络异常体验细化**
- 问题：预览 token 过期、并发收藏、乐观更新回滚提示。
- 模块：导入/书签。
- 影响：体验。优先级：**低**。
- 建议：token 过期时提示"预览已超时，请重新上传"；乐观 mutation 失败回滚+toast。
- 验收：模拟超时/并发，均有明确提示且状态回滚。
