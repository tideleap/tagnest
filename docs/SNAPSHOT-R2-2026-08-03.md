# 网站快照（网站预览图片）功能

> 目标：书签卡片的「网站预览」不再靠远程缩略图，而是走 **第三方截图 API 生成 → 存入 Cloudflare R2 → 卡片展示首方图片** 的完整闭环。

## 架构

```
保存书签 (POST /api/bookmarks)
   └─ snipper 配置时，ctx.waitUntil 异步：
        第三方截图 API (SNAPSHOT_API_URL + Bearer Key)
              └─> R2 对象 snapshots/{userId}/{bookmarkId}.webp
              └─> bookmarks.snapshot_key = 该 key

手动刷新 (POST /api/bookmarks/:id/snapshot)  ← 同一生成链路，同步返回

卡片展示：snapshot_key 存在 → <img src="/api/snapshots/{key}">
          └─> GET /api/snapshots/:key 流式返回对象 + 一年强缓存
```

## 你需要做的（沙箱内无法代办）

### 1. R2 桶
已使用你在 Cloudflare 控制台创建的 `tagnest-media` 桶（APAC 地区）。

### 2. 部署时确认绑定生效
`wrangler.toml` 已加入：
```toml
[[r2_buckets]]
binding = "SNAPSHOT_BUCKET"
bucket_name = "tagnest-media"
```

### 3. 配置环境变量（`wrangler pages secret put` / 面板 Variables）
| 变量 | 必填 | 说明 |
|---|---|---|
| `SNAPSHOT_API_URL` | **否**（有内置默认） | 截图服务地址；支持 `{url}` 占位，会替换为编码后的目标 URL |
| `SNAPSHOT_API_KEY` | 否 | 服务需要鉴权时设置，作为 `Authorization: Bearer <key>` 发送 |

**默认提供方（零配置即用）**：`SNAPSHOT_API_URL` 未设置时，代码自动使用内置的免费
无-key 截图服务 `https://api.sitelookeratter.com/screenshot?url={url}&format=webp`
（GET 直接返回 `image/webp` 字节，命中本功能的契约）。也就是说**只要 R2 桶绑定生效，
快照功能开箱即用**，无需任何环境变量。

如需自管提供方（稳定性 / 配额 / 合规考虑），只需显式设置 `SNAPSHOT_API_URL`——
显式值总是优先于内置默认。已实测当前默认值源可正常返回真实截图：
```
curl 'https://api.sitelookeratter.com/screenshot?url=https%3A%2F%2Fexample.com&format=webp&device=desktop' -o shot.webp
# 返回 200, Content-Type: image/webp, RIFF....WEBP
```

### 4. 迁移
`migrations/0007_snapshot_r2.sql` 新增 `bookmarks.snapshot_key` 列。已在
`scripts/migrate.mjs` 注册 probe。部署时 `deploy.yml` 若无 D1 权限会降级跳过，
列缺失时相关 SELECT 会失败 → 需确保迁移在发布前已应用：
```bash
node scripts/migrate.mjs
```

## 代码清单
- `functions/_lib/snapshots.ts` — 截图 API 调用 + R2 读写 + 错误分类（纯函数，可测）
- `functions/api/bookmarks/[id]/snapshot.ts` — POST 生成并存储（同步）
- `functions/api/snapshots/[key].ts` — GET 流式读取，`Cache-Control: immutable` 一年
- `functions/api/bookmarks/index.ts` — 创建时 `ctx.waitUntil` 自动生成（best-effort）
- `shared/types.ts` / `functions/_lib/db.ts` — `snapshotKey` 字段贯通
- `src/components/bookmark/BookmarkCard.tsx` — 网格卡顶部：快照 → 远程cover → 圆形标
- `tests/snapshots.test.ts` — 11 条单测（in-memory R2 + mock fetch）
