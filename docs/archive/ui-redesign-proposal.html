TagNest · UI 现代化重设计

布局重设计方案

在保留既有暖白品牌与四档响应式骨架的基础上，将现行"扁平直角"界面升级为"毛玻璃 + 圆角卡片 + 柔和阴影 + 渐变点缀"的现代语言——重点是让信息层级更清晰、留白更有节奏，而不是推翻重建。

一、现有布局的结构与问题分析

现状骨架

TagNest 已有一套相当扎实的设计系统：oklch 语义令牌、暖白中性色、琥珀/金红色品牌色、三档圆角与阴影、四档断点（base/md/lg/xl）、响应式侧栏（icon-rail ↔ drawer）。这些是资产，重设计要继承。

当前：扁平直角
  • 圆角偏收紧（sm 6px / md 10px / lg 16px）
  • 侧栏与内容同底色，无悬浮分层
  • 发丝线阴影（–shadow-raised）缺柔光
  • 导航行距 gap 0.5（2px）偏拥挤
  • 页面平铺在画布上，无"浮起"提示
  • 品牌为纯色块，无渐变表达
目标：毛玻璃 + 卡片悬浮
  • 圆角打开（sm 8 / md 14 / lg 20）
  • 侧栏 / 顶栏独立浮层，半透明玻璃
  • 分层柔和阴影，从贴边到悬浮 3 级
  • 分区与导航留白拉开，节奏更从容
  • 主内容承载于圆角卡片上，层级明确
  • 渐变品牌印章 + 柔和强调点缀

7 个具体问题（诊断）

1. 圆角尺度过紧

现有 rounded-md: .625rem(10px)、rounded-lg: 1rem(16px) 在卡片场景偏"工具箱"而非"现代应用"。现代 SaaS 普遍用更放松的圆角传递亲和。

2. 侧栏缺乏悬浮感

侧栏 border-r + bg-surface 与画布同平面，视觉上与内容区是"粘连"的。独立成一个圆角浮层能显著提升现代感。

3. 纯色表面无层次

--p-surface: #fff / 近黑，顶栏用了 backdrop-blur 但侧栏与移动抽屉完全实心，玻璃质感未铺开。

4. 阴影发丝化

--shadow-raised: 0 1px 2px 几乎不可见；没有"贴边/浮动/弹出"三级层高来区分静态面板与可交互卡片。

5. 导航行距拥挤

主/次导航 gap-0.5、行高 h-9，8 个常点入口挤在一起。分组间缺呼吸，次级功能与主功能边界模糊。

6. 内容区无层级承载

页面自绘在画布上，各区块靠自身 border 区隔，"内容浮在背景上"的主次关系没有建立。

7. 品牌缺渐变表达

品牌色是纯 #922900 色块，仅卡通 dashboard 用彩色 blob。主入口按钮 / 封面卡若用温和渐变，品牌"印章感"更强。

设计取向

克制地现代化：保留暖白中性色与琥珀品牌色（这是既有辨识度），以「玻璃分层 + 圆角卡片 + 柔和阴影 + 一处渐变印章」为骨架重梳布局。不做游戏化的渐变铺满，也不引入新的品牌色——让"更留白的层级"自己说话。

二、整体设计方案

1. 视觉风格 · 玻璃分层 + 圆角卡片

以三档"悬浮层级"取代纯平铺陈：

  • L0 贴地平铺：页面容器、静态说明。白底 + 细边框 + 极轻阴影。
  • L1 浮起卡片：指标卡、可点卡片、表单面板。rounded-lg + shadow-md + hover 抬升。
  • L2 玻璃悬浮：侧栏、顶栏、命令面板、弹窗。半透明 bg + backdrop-blur + 中距阴影。
玻璃实现用现有工具箱即可：Tailwind v4 的 bg-*/70 + backdrop-blur（顶栏已在用 bg-canvas/85），无需引入依赖。暗色主题下降低透明以满足 WCAG 对比度。

2. 布局结构 · 分区与主次

  1. 侧栏（L2 玻璃浮层）：品牌 → 主功能（概览/收件箱/全部/收藏/归档） → 常用标签 → 次功能（AI整理/标签/标签页组/导入/回收站/设置）。分组间用 gap-3 拉开，主动画描边保留。
  2. 顶栏（L2 玻璃条）：移动端汉堡 → 全局搜索（右侧 `/` 快捷键） → 「+ 添加」主按钮 → 主题切换 → 账户。搜索框由全宽改为 max-w 束窄，右侧让位给行动项。
  3. 主内容（L0）：以 max-w-7xl 居中，页头（eyebrow + 标题 + 描述 + 行动项）固定为统一 PageHeader；下方数据承载到 L1 圆角卡片。xl 时侧栏 240px，内容留白 px-8。
  4. 移动端：抽屉侧栏 + 底部 TabBar（中间 + 按钮）不变，卡片栅格切单列。

3. 色彩与字体

色彩沿用既有令牌，新增"玻璃/层次"相关语义。字体层级微调，标题字号与字重更明确。

主色 brand-gradient
品牌印章改为温和渐变 linear-gradient(135deg, brand, brand-accent)——用于「+添加」/推荐页 Hero / 选中态。
画布 canvas
保持暖白 oklch(.985 .003 85)。可替换顶部大面积区域为极浅的品牌色晕染作"氛围底"，增强沉浸而不抢内容。
卡片 surface
#fff 白底作为 L1/L2 承载面；玻璃态用 surface/70 + blur，保证文字对比度 ≥4.5:1。
强调 brand-soft / brand-accent
soft 底用于选中 nav 与徽标底；accent 金红用于勾选描边、hover 图标、页码高亮。

4. 交互细节 · 动效

  • 按钮：主按钮 hover 微上浮 + 柔和阴影扩散；点击保留现有 ripple。渐变主按钮 transition: transform .15s, box-shadow .15s，上升 -translate-y-px。
  • 卡片（L1 可交互）：沿用 .card-interactive（hover 抬升 + 阴影 + 边框加深），统一到所有可点卡片；静态面板不抬升，避免误用。
  • 导航项：图标 hover 微放大（group-hover:scale-105）+ 左缘 accent 条淡入（现已有，保留）；行距增大提升命中区。
  • 进入/滚动：区块滚动进场 .reveal-card（已有，IntersectionObserver），从"整页同现"改为"分段上浮"，节奏更现代；prefers-reduced-motion 下全部禁用（已有）。
  • 焦点态：保留 :focus-visible 2px 品牌描边，键盘可操作性不因美观牺牲。

5. 响应式适配

断点布局要点
base (<768)手机底栏 TabBar + 抽屉侧栏；卡片单列；Hero 堆叠；主按钮由顶栏移入内容区
md (768)平板纵侧栏 → icon-rail 56px（标签隐藏）
lg (1024)笔记本侧栏展开 180px 圆角浮层；主内容进 lg:pl-60
xl (1280+)桌面侧栏 240px；内容 px-8，指标卡 3–4 列

栅格用 repeat(auto-fit, minmax(280px, 1fr)) 承载书签/指标，避免固定列数在小屏溢出。所有新增视觉（玻璃、圆角、阴影）均为纯 CSS，不增加包体。
