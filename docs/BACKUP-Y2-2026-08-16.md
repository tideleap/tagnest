# B-7 Y2 WebDAV/S3 备份推送 — 设计决策（2026-08-16）

## 目标
将完整书签库导出包**定时/手动**推送到用户自有存储（WebDAV / S3）。凭据服务端加密存储，推送可验证、有历史。完成标准：可配置、可验证、凭据加密存储。

## 现状调研（复用优先，不重复造轮子）
- **导出包已就绪**：`functions/api/export.ts` 的 `renderJsonStream` 产出标准 JSON 包
  `{application:"TagNest",version:1,exportedAt,bookmarks,collections}`（流式）。备份 = 同一包
  PUT 到远端而非下载给用户。已遵守 `PRIVATE_BOOKMARK_CLAUSE`（私密书签永远不出库）。
- **字段加密已就绪**：`functions/_lib/crypto.ts` 提供 `encryptField(plaintext, env)` /
  `decryptField(stored, env)` —— AES-256-GCM，密钥由 `JWT_SECRET` 经 HKDF 派生（domain
  separation，fail-closed）。直接复用作 WebDAV 密码 / S3 密钥的加密存储，无需新算法。
- **无 cron 触发器**：`wrangler.toml` 仅 D1 / KV(SHARE_CACHE) / R2(SNAPSHOT_BUCKET) / BROWSER
  绑定，无 `[triggers] cron`。定时调度需新增配置（部署期生效，沙箱无法验证 cron 触发）。
- **设置页无 Backup 区块**：现有 Account / Ai / ApiKeys / Shares / Snapshots / Storage / Jobs
  等。JobsSection 是 AI job 历史（列表 + 状态徽标 + 相对时间），模式可借鉴。

## 数据模型（迁移 0020）
```sql
CREATE TABLE backup_targets (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  kind TEXT NOT NULL,            -- 'webdav' | 's3'
  endpoint TEXT NOT NULL,        -- WebDAV base URL 或 S3 https://bucket.s3.region.amazonaws.com
  bucket TEXT,                   -- S3 专用，可空
  username TEXT,
  encrypted_secret TEXT,         -- encryptField(password / secret_key)，明文不落库
  remote_path TEXT NOT NULL DEFAULT '/',  -- 远端目录
  enabled INTEGER NOT NULL DEFAULT 1,
  frequency TEXT NOT NULL DEFAULT 'off', -- 'off' | 'daily' | 'weekly'
  last_run_at TEXT,
  last_status TEXT,              -- 'ok' | 'failed' | NULL
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX idx_backup_targets_user ON backup_targets(user_id);

CREATE TABLE backup_runs (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  target_id TEXT NOT NULL,
  started_at TEXT NOT NULL,
  finished_at TEXT,
  status TEXT NOT NULL,          -- 'ok' | 'failed'
  bytes INTEGER,
  sha256 TEXT,
  error TEXT
);
CREATE INDEX idx_backup_runs_user ON backup_runs(user_id, started_at DESC);
```

## 后端端点（`functions/api/backup/`）
- `GET /api/backup/targets`：列出当前用户目标。**不返回 secret**，只回 kind/endpoint/
  bucket/enabled/frequency/last_run_at/last_status。
- `PUT /api/backup/targets`：upsert（单用户允许多目标，按 id 或 kind+endpoint 匹配）。
  明文 `secret` 入参 → `encryptField` 存储；省略 secret = 不变（镜像 B-4 的 PATCH 哨兵语义）。
- `DELETE /api/backup/targets/:id`：删除目标 + 其历史。
- `POST /api/backup/run`：立即对所有 `enabled` 目标推送；body 可选 `targetId` 指定单个。
- `GET /api/backup/runs`：最近 50 条推送历史（含 target kind/endpoint 摘要）。

## 导出包收集（复用 export.ts）
新增 `collectExportBody(env, userId, opts)`：消费 `renderJsonStream` 的 `ReadableStream`，
`Response.body` 读成完整字符串（`await new Response(stream).text()`）。小库 OK；大库后续可经
R2 中转（MVP 内存接受，文档标注）。

## 远端客户端（Workers 环境无 Node fs，全部用 fetch）
- **`_lib/webdav.ts` · `webdavPut(target, body)`**：
  1. `PROPFIND` 远端路径 → 404 则逐级 `MKCOL` 建目录；
  2. `PUT` 文件 `tagnest-YYYY-MM-DD.json`（`Content-Type: application/json`）。
- **`_lib/s3.ts` · `s3Put(target, body)`**：AWS SigV4 签名 `PUT`（region / accessKey /
  secretKey 来自目标配置），复用 `fetch`。
- 推送后 **GET/HEAD 远端校验字节数**（或 ETag），成功写 `backup_runs` (status=ok + bytes +
  sha256)，失败写 (status=failed + error)。

## 定时调度（增强，非阻塞交付）
- `wrangler.toml` 加 `[[triggers]] crons = [...]`，`functions/_scheduled.ts` 遍历 enabled 目标
  调 run。沙箱无法验证 cron 触发，MVP 先实现**手动 run + frequency 字段存储**，cron 仅文档说明。

## 前端（`src/pages/settings/BackupSection.tsx`）
- 配置卡：kind 选择（WebDAV/S3）、endpoint/url、bucket、username、secret、remote_path、
  enabled 开关、frequency 选择。
- 操作：保存（toast）、立即备份（loading + 成功/失败 toast）。
- 历史列表：复用 JobsSection 模式（状态徽标 + 相对时间 + 字节数 + 错误展开）。
- 路由：设置页新增「备份」区块（SettingsPage 注册）。
