TTagNest

隐私政策 · Privacy Policy

适用于「TagNest 一键收纳」浏览器扩展（Chrome / Edge / Firefox）
生效日期 / Effective date：2026-08-28 · 版本 1.0

一句话总结 / TL;DR

这个扩展不收集、不上传、不分析你的任何浏览数据用于我们（开发者）的目的。它只做一件事：在你主动点击时，把当前网页的网址和标题（以及你可选填写的笔记）发送到你自己部署的 TagNest 实例。你的 API 密钥只保存在本机浏览器里。

✓ 无分析统计 ✓ 无第三方追踪 ✓ 无广告 ✓ 数据只发往你自己的服务器

1. 我们访问哪些数据 / What we access

数据何时读取用途
当前标签页的网址与标题你点击「收藏当前页」或「收纳窗口」时生成要保存的书签
页面上的选中文字仅当你用快捷键收藏且页面上有选区时存为该书签的笔记（可选）
浏览器书签树仅当你主动触发「双向同步」并授予书签权限时在浏览器书签与 TagNest 之间对账同步
你填写的服务器地址与 API 密钥你在扩展设置页填写时连接你自己的 TagNest 实例

除上述场景外，扩展不会在后台读取、扫描或上传任何页面内容。

2. 数据发送到哪里 / Where data goes

所有网络请求都只发往你在设置页填写的 TagNest 服务器地址（例如 https://tagnest.pages.dev 或你自己的部署地址），通过 HTTPS 传输，并以你的个人 API 密钥（tnk_...）鉴权。

我们不运营任何数据收集服务器，扩展不会向开发者或任何第三方发送你的浏览数据、书签或密钥。

3. 数据如何存储 / How data is stored

  • 服务器地址与 API 密钥：仅保存在你本机浏览器的 chrome.storage.local，不会同步到浏览器云端，也不会离开你的设备（除了按你的指令发往你自己的 TagNest 服务器）。
  • 书签内容：保存在你自己的 TagNest 实例的数据库中，受该实例自身的隐私与访问控制约束。
  • 同步状态（上次同步时间、快照）保存在本机 chrome.storage.local，用于增量同步与回滚。

4. 权限说明 / Permissions

权限用途
activeTab / tabs读取你要收藏的标签页的网址与标题
storage在本机保存服务器地址、密钥与同步状态
scripting仅在你主动收藏时读取当前页选区文字
alarms按计划执行你订阅源的定时刷新（如启用）
bookmarks（可选，按需授权）仅在你使用「双向同步」时请求，用于读写浏览器书签栏中的 TagNest 文件夹

扩展不声明任何主机权限（host permissions），不在页面中注入脚本，所有网络请求均由后台 Service Worker 发出——这把你的攻击面降到最低。

5. 我们不做什么 / What we do NOT do

  • 不收集、不上报任何使用统计或遥测数据；
  • 不向任何第三方（广告、分析、数据经纪）共享你的数据；
  • 不在页面中注入内容脚本以读取与收藏无关的信息；
  • 不请求访问你的浏览历史、密码、表单内容等无关数据；
  • 密钥无权访问 /api/keys 与 /api/auth，即使泄露也无法自助签发更多密钥。

6. 你的控制 / Your control

  • 随时在扩展设置页清除服务器地址与密钥；
  • 在浏览器扩展管理页撤销任意权限或卸载扩展；
  • 卸载后，本机 chrome.storage.local 中的扩展数据将被浏览器清除。

7. 儿童隐私 / Children's privacy

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

8. 变更与联系 / Changes & contact

如本政策有重大变更，我们会更新本页并标注生效日期。继续使用扩展即视为接受更新后的政策。

English Summary

This extension does not collect, upload, or analyze your browsing data for the developer's purposes. It only sends the URL and title of the page you choose to save (plus an optional note) to your own self-hosted TagNest instance over HTTPS. Your API key is stored only in your local browser storage and never synced to the cloud. The extension declares no host permissions, injects no content scripts, and makes no requests to any third party. There is no analytics, no tracking, and no ads.

Questions? Contact privacy@ddxz6780.xyz.
