# TagNest 一键收纳（浏览器扩展）

一个 Manifest V3 扩展，让你在不打开 TagNest 网站的情况下也能：
- **收藏当前页** —— 一键把正在看的网页存入书签库
- **收纳整个窗口** —— 把当前窗口所有可收藏标签页一次归档，并自动归入一个「标签页组」

依托你的 TagNest 实例的 **个人访问密钥**（`tnk_...`）通过 HTTPS 直连，不在页面里注入任何脚本。

## 功能

| 能力 | 入口 | 说明 |
|------|------|------|
| 收藏当前页 | 扩展弹窗「＋收藏当前页」 | 幂等：重复收藏会复用已有书签，不产生重复 |
| 收纳整个窗口 | 扩展弹窗 / Ctrl+Shift+T | 逐页收藏 → 自动建组「N 个标签页」→ 全部归入该组 |
| 连接状态 | 弹窗顶部状态点 | 显示是否已配置且可达 |
| 测试连接 | 设置页「测试连接」 | 校验服务器可达、密钥有效 |
| 深色模式 | 跟随系统 | 沿用 TagNest 琥珀品牌色与暖中性背景 |

只会读取标签页的 `url` 与 `title`，只请求 `activeTab`、`tabs`、`storage` 三个最小权限，不声明任何主机权限。

## 安装

1. 打开浏览器扩展管理页（Chromium：`chrome://extensions`；Edge：`edge://extensions`）。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录（`extension/`）。
4. （可选）在扩展详情里把键盘快捷键设为 Ctrl+Shift+T。

> 图标由 `build-icons.mjs` 生成（仅依赖 Node 内置模块）。修改后运行 `node build-icons.mjs` 重新生成。

## 配置

1. 点击扩展图标 → 右下角「设置」。
2. 填写 **TagNest 服务器地址**（你的部署地址，如 `https://tagnest.pages.dev`）。
3. 到 TagNest 网站 **设置 → API 密钥** 新建一个带 **读写** 权限的密钥，复制 `tnk_...`。
4. 粘贴密钥，点击「保存」，建议点「测试连接」确认。
5. 关闭设置页，即可开始一键收纳。

## 设计

- `manifest.json` —— MV3 清单，权限与快捷键
- `bg/` —— 后台：配置文件（`config.js`）、API 客户端（`api.js`）、标签页采集（`tabs.js`）、整窗收纳编排（`capture-window.js`）、Service Worker（`service-worker.js`）
- `popup/` —— 弹出面板（收藏当前页 / 收纳窗口）
- `options/` —— 设置页（服务器地址、密钥、测试连接）
- `icons/` —— 商标图标

## 安全说明

- 密钥只保存在 `chrome.storage.local`（不同步到云端）。
- 不用主机权限：网络请求全部由后台 Service Worker 发出，密钥不会暴露到任意网站页面。
- 扩展密钥无权访问 `/api/keys` 与 `/api/auth`（后端中间件强制），泄露也无法自助签发更多密钥。
